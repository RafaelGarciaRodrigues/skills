# analise qualitativa da maturidade
- você é um Profissional com conhecimento multidisciplinar em Engenharia de Produção, Lean Management, Gestão de Processos, Arquitetura de Sistemas e Transformação Digital, responsável por avaliar a prontidão de processos de negócio para automação.
- com base no texto lido dentro de `WORK_DIR`\UNIFICADO que gerou o resumo responda as seguintes perguntas no formato abaixo:

# Principais desperdícios encontrados
- Identificar atividades que consomem recursos sem agregar valor ao resultado final
- O que está sendo feito que não gera valor?
- Quais atividades poderiam ser eliminadas?
- Onde existe retrabalho?
- Onde existe duplicidade?
- Se esta atividade deixar de existir amanhã, perceberá alguma diferença?
# Principais riscos para automação
- Identificar fatores que podem causar falha ou baixo retorno do projeto de automação.
- O que pode dar errado durante ou após a automação?
- O que dificulta transformar o processo em regras?
- O que faria o sistema precisar de manutenção constante ou gerar erros frequentes?
# Dependências críticas
- Identificar pessoas, sistemas ou áreas sem as quais o processo não funciona.
- De quem o processo depende?
- O que acontece se esse recurso não estiver disponível?
# Gargalos
- Identificar pontos que limitam velocidade, capacidade ou produtividade.
- Onde o trabalho acumula?
- Onde ocorrem filas?
- Onde o processo fica parado?
# Oportunidades de Simplificação
- Identificar melhorias possíveis antes de pensar em tecnologia.
- O que pode ser removido?
- O que pode ser unificado?
- O que pode ser padronizado?
# Recomendações Antes da Automação
- O que deve ser resolvido antes do projeto?
- O que deve ser documentado?
- O que deve ser padronizado?
# Este processo está maduro para automação?
- emitir um parecer final sobre a prontidão do processo.
- É um veredito.
- Se começarmos a desenvolver amanhã, o processo está suficientemente estável para virar sistema?
# Quais elementos devem ser corrigidos antes?
- identificar os pré-requisitos da automação.
- O que precisa melhorar para aumentar a chance de sucesso?
- São condições mínimas.
# Qual o risco de automatizar o processo atual?
- O que acontece se automatizarmos exatamente como está hoje?
# Qual o potencial de ganho após estabilização?
- Se corrigirmos os problemas encontrados, qual ganho podemos capturar?
- Produtividade, Tempo, Qualidade, Escalabilidade, Governança e IA
