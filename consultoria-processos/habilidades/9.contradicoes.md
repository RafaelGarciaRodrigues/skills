# Contradições e conflitos

Com base no texto lido dentro de `WORK_DIR`\UNIFICADO que gerou o resumo, liste contradições, ambiguidades e conflitos:

- liste no mínimo 5, sem limite de máximo
- título curto que deixe claro o tema da contradição
- citação_a: primeira citação que compõe a contradição (com autor)
- citação_b: segunda citação que compõe a contradição (com autor)
- se o nome do autor não aparecer no trecho, use "Não identificado"
- descrição explica por que os trechos se contradizem ou conflitam

## Formato de saída

Responda APENAS com o JSON abaixo, sem nenhum texto antes ou depois, sem blocos de código markdown:

```
{"9.contradicoes": [
  {
    "titulo": "Prazo de entrega vs. escopo definido",
    "citacao_a": {"autor": "Thaís", "texto": "citação literal aqui"},
    "citacao_b": {"autor": "Pedro", "texto": "citação literal conflitante aqui"},
    "descricao": "Explicação do motivo pelo qual os trechos se contradizem."
  },
  {
    "titulo": "Outra contradição",
    "citacao_a": {"autor": "Nome", "texto": "citação A"},
    "citacao_b": {"autor": "Nome", "texto": "citação B"},
    "descricao": "Descrição da contradição."
  }
]}
```

Regras do JSON:
- A chave raiz é exatamente `"9.contradicoes"`
- O valor é um array de objetos com: `titulo` (string), `citacao_a` (objeto com `autor` e `texto`), `citacao_b` (objeto com `autor` e `texto`), `descricao` (string)
- Aspas dentro de strings devem ser escapadas com `\"`
