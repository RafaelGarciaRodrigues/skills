# Determinar o Problema Central
- com base no texto lido que gerou o resumo forme uma frase que caracteriza o problema central abordado no texto em `WORK_DIR`\UNIFICADO
- frase simples e resumida
- no máximo 70 caracteres

## Formato de saída

Responda APENAS com o JSON abaixo, sem nenhum texto antes ou depois, sem blocos de código markdown:

```
{"2.problema-central": "frase curta do problema central"}
```

Regras do JSON:
- A chave é exatamente `"2.problema-central"`
- O valor é uma string curta (máx. 70 caracteres)
