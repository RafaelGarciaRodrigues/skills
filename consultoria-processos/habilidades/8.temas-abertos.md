# Temas que ficaram sem definição

Com base no texto lido dentro de `WORK_DIR`\UNIFICADO que gerou o resumo, liste os assuntos que foram abordados mas não tiveram fechamento ou definição clara:

- título deve ser curto e descritivo
- descrição explica o assunto abordado
- motivo explica por que o tema ficou em aberto

## Formato de saída

Responda APENAS com o JSON abaixo, sem nenhum texto antes ou depois, sem blocos de código markdown:

```
{"8.temas-abertos": [
  {
    "titulo": "Integração com Data Lake",
    "descricao": "Discussão sobre quais sistemas alimentariam o solver via pipeline ETL.",
    "motivo": "Nenhuma decisão foi tomada sobre responsável ou prazo para estruturação do pipeline."
  },
  {
    "titulo": "Outro tema",
    "descricao": "Descrição do tema.",
    "motivo": "Motivo pelo qual ficou aberto."
  }
]}
```

Regras do JSON:
- A chave raiz é exatamente `"8.temas-abertos"`
- O valor é um array de objetos, cada um com: `titulo` (string curta), `descricao` (string), `motivo` (string)
- Aspas dentro de strings devem ser escapadas com `\"`
