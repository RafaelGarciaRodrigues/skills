# Lista de necessidades

Com base no texto lido dentro de `WORK_DIR`\UNIFICADO que gerou o resumo, identifique todas as necessidades abordadas:

- no mínimo 7 necessidades, sem limite de máximo
- ordenadas por relevância decrescente
- titulo da necessidade deve ser uma frase curta
- titulo não deve começar com verbo de ação — necessidade não é uma ação
- necessidade não é um pedido e nem um requisito — é uma causa raiz de problema
- a descrição é uma explicação detalhada
- se necessário, inserir citações entre aspas do texto que originou a necessidade
- relevância: inteiro de 0 a 100 que indica a importância da necessidade (quantidade de texto que aborda o tema ou citações explícitas de importância)

## Formato de saída

Responda APENAS com o JSON abaixo, sem nenhum texto antes ou depois, sem blocos de código markdown:

```
{"4.necessidades": [
  {
    "titulo": "Título curto da necessidade",
    "relevancia": 92,
    "descricao": "Explicação detalhada da necessidade. \"Citação do texto entre aspas escapadas.\""
  },
  {
    "titulo": "Segunda necessidade",
    "relevancia": 80,
    "descricao": "Descrição da segunda necessidade."
  }
]}
```

Regras do JSON:
- A chave raiz é exatamente `"4.necessidades"`
- O valor é um array de objetos, cada um com: `titulo` (string), `relevancia` (inteiro 0-100), `descricao` (string)
- Aspas dentro de strings devem ser escapadas com `\"`
- Quebras de linha dentro de strings devem usar `\n`
- O array deve estar ordenado por `relevancia` decrescente
