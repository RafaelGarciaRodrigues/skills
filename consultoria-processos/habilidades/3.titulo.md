# Determinar o Título
- com base no texto lido que gerou o resumo forme um título curto baseado na transcrição em `WORK_DIR`\UNIFICADO
- titulo deve ser mais curto que a frase do problema definida no passo anterior

## Formato de saída

Responda APENAS com o JSON abaixo, sem nenhum texto antes ou depois, sem blocos de código markdown:

```
{"3.titulo": "Título do Projeto"}
```

Regras do JSON:
- A chave é exatamente `"3.titulo"`
- O valor é uma string curta
