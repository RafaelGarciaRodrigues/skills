# Diagnóstico de Maturidade — Duas Dimensões

Você é um especialista em Engenharia de Produção, Lean Manufacturing e Automação de Sistemas.

Com base no texto em WORK_DIR\UNIFICADO, realize dois diagnósticos independentes:

---

## Diagnóstico 1 — Conhecimento do Processo

Avalie o quanto a equipe CONHECE o processo — não o quanto o processo é bom,
mas **o quanto ele é compreendido**. Um processo caótico bem compreendido recebe
nota alta aqui; um processo que ninguém sabe descrever recebe nota baixa.

Avalie cada sub-dimensão com nota 0–5:

| Nota | Significado |
|------|-------------|
| 5 | Completamente claro e documentado, sem ambiguidades |
| 4 | Bem compreendido, pequenas lacunas não críticas |
| 3 | Compreendido parcialmente, lacunas conhecidas |
| 2 | Pouco compreendido, dependências tácitas relevantes |
| 1 | Quase desconhecido, apenas fragmentos disponíveis |
| 0 | Informação insuficiente para avaliar |

Sub-dimensões:
1. **Clareza do fluxo** — o processo de ponta a ponta é descritível sem ambiguidade?
2. **Padronização** — é executado da mesma forma por pessoas diferentes?
3. **Regras de decisão** — os critérios estão documentados e formalizados?
4. **Rastreabilidade** — as etapas podem ser auditadas e têm rastro?
5. **Independência tácita** — qualquer pessoa treinada consegue executar?
6. **Alinhamento de stakeholders** — todos concordam sobre o que é e o que será automatizado?
7. **Disponibilidade de dados** — os dados estão acessíveis de forma estruturada?

---

## Diagnóstico 2 — Perdas Toyota Identificadas

Avalie quais das 8 perdas do Sistema Toyota estão PRESENTES no processo
e a severidade de cada uma.

| Severidade | Significado |
|------------|-------------|
| 3 | Grave — impacta diretamente resultado, tempo ou qualidade |
| 2 | Moderada — presente e visível, mas não bloqueia o processo |
| 1 | Leve — identificada, impacto limitado |
| 0 | Ausente — não identificada neste processo |

As 8 perdas:
1. **Superprodução** — fazer mais do que o necessário antes de ser necessário
2. **Espera** — tempo de inatividade aguardando informação, decisão ou execução
3. **Transporte** — movimentação desnecessária de informação ou material
4. **Processamento Excessivo** — etapas que não agregam valor ao output final
5. **Estoque** — acúmulo de informação ou trabalho em progresso sem processamento
6. **Movimento** — esforço desnecessário de pessoas para executar a tarefa
7. **Defeitos/Retrabalho** — erros que precisam ser corrigidos ou refeitos
8. **Conhecimento Não Utilizado** — especialistas fazendo trabalho delegável ou automatizável

## Formato de saída

Responda APENAS com o JSON abaixo, sem texto antes ou depois,
sem blocos de código markdown:

{
  "10.maturidade": {
    "conhecimento": {
      "dimensoes": [
        {"nome": "Clareza do fluxo",             "nota": 0, "justificativa": ""},
        {"nome": "Padronização",                  "nota": 0, "justificativa": ""},
        {"nome": "Regras de decisão",             "nota": 0, "justificativa": ""},
        {"nome": "Rastreabilidade",               "nota": 0, "justificativa": ""},
        {"nome": "Independência tácita",          "nota": 0, "justificativa": ""},
        {"nome": "Alinhamento de stakeholders",   "nota": 0, "justificativa": ""},
        {"nome": "Disponibilidade de dados",      "nota": 0, "justificativa": ""}
      ]
    },
    "perdas": {
      "itens": [
        {"perda": "Superprodução",           "severidade": 0, "descricao": ""},
        {"perda": "Espera",                  "severidade": 0, "descricao": ""},
        {"perda": "Transporte",              "severidade": 0, "descricao": ""},
        {"perda": "Processamento Excessivo", "severidade": 0, "descricao": ""},
        {"perda": "Estoque",                 "severidade": 0, "descricao": ""},
        {"perda": "Movimento",               "severidade": 0, "descricao": ""},
        {"perda": "Defeitos/Retrabalho",     "severidade": 0, "descricao": ""},
        {"perda": "Conhecimento Não Utilizado","severidade": 0, "descricao": ""}
      ]
    }
  }
}

Regras do JSON:
- Aspas internas escapadas com \"
- Sem quebras de linha dentro de strings
- "nota" é inteiro 0–5; "severidade" é inteiro 0–3
- "descricao" deve ser vazia ("") quando severidade = 0
- Inclua TODOS os 7 itens de conhecimento e TODOS os 8 itens de perdas
- O quadrante e a ação são calculados automaticamente pelo sistema
