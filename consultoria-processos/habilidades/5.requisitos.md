# Lista de necessidades
- com base no texto lido dentro de `WORK_DIR`\UNIFICADO que gerou o resumo forme:
-- uma lista identificando todos os requisitos abordados
-- no mínimo 7 requisitos, não se limitando a 7, pode ser mais sem limite de máximo
-- deve ser composto por título e descrição e texto no formato markdown por exemplo:
-- identificar a origem de cada requisito:
--- 'CONTEXTO' se o requisito foi tirado do texto dos aquivos em `WORK_DIR`\UNIFICADO
--- 'INSIGHTS' se o requisito é um insight que não foi abordado no texto
#TITULO DO REQUISITO - (RELEVÂNCIA)
## IDENTIFICAÇÃO DO REQUISITO: 'CONTEXTO' OU 'INSIGHT'
-DESCRIÇÃO DO REQUISITO

#[TITULO DO REQUISITO] - (RELEVÂNCIA)
## [ IDENTIFICAÇÃO DO REQUISITO: 'CONTEXTO' OU 'INSIGHT']
-[DESCRIÇÃO DO REQUISITO]

-- titulo do requisito deve ser uma frase curta
-- titulo são ações ou soluções solicitadas
-- necessidade não é um problema, necessidade ou dificuldade

-- a descrição do requisito é uma explicação detalhada
-- se necesário inserir citações entre aspas do texto que gerou a identificação do requisito

-- relevância: é um valor inteiro de 0 a 100 que determina a relevância desse requisito no texto
-- avalie a relevância para atribuir um valor analisando a quantidade de texto que o assunto aborda a determinado requisito ou alguma citação específica falando de sua importância ou se há uma necessidade com alta relevância que é atendida por esse requisito
-- insira o valor da relevância entre () após o TITULO DO REQUISITO no formato: #TITULO DO REQUISITO - (RELEVÂNCIA)

- crie a lista de requisitos por ordem decrescente de relevância

-- quando for um insights
--- crie no mínimo 3 insights
--- ideias acionáveis não discutidas nos arquivos dentro de `WORK_DIR`\UNIFICADO
--- se comporte como analista de estratégia: direto, sem elogio, sem coaching. Curtas, com porquê mínimo. Aponte riscos se houver. Nada genérico sem um 'como'."
--- na descrição quando for 'INSIGHT' insira uma bibliografia de referência que está relacionada ao insight sugerido
