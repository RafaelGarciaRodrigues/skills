# Mapa mental em Markdown

Com base no texto lido dentro de `WORK_DIR`\UNIFICADO que gerou o resumo, construa um mapa mental:

- Inicia com macro tema > problemas > causas raiz / soluções (responsável + data se houver) / insights / números
- Hierárquico, máximo detalhe, sem resumir, sem inventar, sem introdução/conclusão
- Sem ``` no início/fim do markdown

## Formato de saída

Responda APENAS com o JSON abaixo, sem nenhum texto antes ou depois, sem blocos de código markdown:

```
{"6.mapa-mental": "# Macro Tema\n## Subtema\n- item\n  - subitem\n  - subitem"}
```

Regras do JSON:
- A chave é exatamente `"6.mapa-mental"`
- O valor é uma string contendo o markdown do mapa mental completo
- Quebras de linha devem ser representadas como `\n` (escape JSON)
- NÃO use ``` dentro do valor — o markdown vai direto como string
