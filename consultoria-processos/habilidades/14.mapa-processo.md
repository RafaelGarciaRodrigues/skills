Você é um especialista em Engenharia de Produção, Lean Manufacturing e
Mapeamento de Processos.

Com base nas informações contidas em WORK_DIR\UNIFICADO, mapeie o processo
descrito — do início até a entrega final — em etapas cronológicas.

---

# Regras de mapeamento

## Etapas (macro)
- Identifique entre 5 e 9 etapas principais em ordem cronológica de execução.
- Cada etapa representa um bloco de trabalho com objetivo próprio.
- O ÚLTIMO elemento do array "processo" deve ser a etapa de entrega do
  resultado final (produto ou serviço gerado pelo processo).

## Campos por etapa
- "ordem": inteiro sequencial (1, 2, 3...)
- "titulo": máximo 4 palavras, nome da etapa
- "explicacao": 1 a 2 frases descrevendo o que acontece nessa etapa
- "gargalo": true se a etapa concentra espera, retrabalho, dependência de
  pessoa específica ou interrupção recorrente do fluxo; false caso contrário
- "maturidade": inteiro de 1 a 5, avaliando o quanto essa etapa está
  estável e pronta para automação:
    1 = completamente manual, sem padronização, caótica
    2 = executada mas variável, com problemas conhecidos
    3 = padronizada informalmente, alguns critérios claros
    4 = padronizada, replicável, com poucos problemas
    5 = estável, documentada, pronta para automação
- "perda_toyota": qual das 8 perdas do Sistema Toyota de Produção é mais
  evidente nessa etapa. Use exatamente um dos valores abaixo, ou deixe
  em branco "" se não houver perda identificável:
    "Superprodução"
    "Espera"
    "Transporte"
    "Processamento Excessivo"
    "Estoque"
    "Movimento"
    "Defeitos"
    "Conhecimento Não Utilizado"

## Micro-etapas (dentro de cada etapa)
- Identifique entre 2 e 5 micro-etapas por etapa principal.
- Selecione as mais representativas — as que melhor explicam como a
  etapa é executada na prática.
- Campos por micro-etapa:
    "titulo": máximo 5 palavras
    "explicacao": 1 frase
    "gargalo": true se é o ponto de maior atrito dentro da etapa
    "manual": true se executada manualmente por uma pessoa;
              false se automatizada ou semi-automatizada

## Entrega final
- Após o array "processo", inclua um objeto "entrega" com:
    "titulo": nome do produto ou serviço entregue ao final do processo
    "explicacao": o que é esse resultado e quem o recebe

# Formato de saída

Responda APENAS com o JSON abaixo, sem texto antes ou depois,
sem blocos de código markdown:

{
  "processo": [
    {
      "ordem": 1,
      "titulo": "",
      "explicacao": "",
      "gargalo": false,
      "maturidade": 3,
      "perda_toyota": "",
      "micro_etapas": [
        {
          "titulo": "",
          "explicacao": "",
          "gargalo": false,
          "manual": true
        }
      ]
    }
  ],
  "entrega": {
    "titulo": "",
    "explicacao": ""
  }
}

Regras do JSON:
- Aspas internas escapadas com \"
- Sem quebras de linha dentro de strings
- "processo" é um array de 5 a 9 objetos
- "micro_etapas" é um array de 2 a 5 objetos por etapa
- "manual": true = manual, false = automatizado
- "gargalo": use true com parcimônia — no máximo 3 etapas macro
  e no máximo 1 micro-etapa por etapa podem ser gargalo
