# Números falados no texto

Com base no texto lido dentro de `WORK_DIR`\UNIFICADO que gerou o resumo, liste todos os números mencionados:

- inclua valores monetários, percentuais, quantidades, prazos, volumes, datas relevantes
- o título define o que o número representa
- o contexto explica a situação em que o número foi mencionado

## Formato de saída

Responda APENAS com o JSON abaixo, sem nenhum texto antes ou depois, sem blocos de código markdown:

```
{"7.numeros": [
  {
    "valor": "R$ 700 milhões",
    "titulo": "Custo de frete VHP por safra",
    "contexto": "Frase explicativa com o contexto em que esse número aparece no texto."
  },
  {
    "valor": "3 a 5 dias",
    "titulo": "Ciclo de rolagem de contratos",
    "contexto": "Contexto do número."
  }
]}
```

Regras do JSON:
- A chave raiz é exatamente `"7.numeros"`
- O valor é um array de objetos, cada um com: `valor` (string com o número/valor), `titulo` (string curta que define o número), `contexto` (string com frase explicativa)
- Aspas dentro de strings devem ser escapadas com `\"`
